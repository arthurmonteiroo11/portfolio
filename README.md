# Arthur Monteiro - Portfolio

A minimalist, high-performance personal portfolio and developer showcase built with React, Vite, and advanced CSS grid & cursor spotlight effects.

## Overview

This repository contains my personal portfolio website, designed to showcase my projects, professional background, and core technical skills as a front-end developer and computer science student. It features a geometric grid background, text gradients, interactive cursor spotlight cards, smooth entry animations, and a clean modular component architecture.

## Stack & Technologies

- **Core:** React, Vite, JavaScript (ES6+)
- **Styling & Animations:** Custom CSS3 (Grid patterns, Text Gradients, Radial Spotlight effects, Glassmorphism)
- **Version Control:** Git & GitHub (`arthurmonteiroo11`)
- **Deployment:** Vercel

## Modular Architecture (`src/components/`)

- **Navbar.jsx:** Header navigation links and external profiles.
- **Hero.jsx:** Introduction, gradient typography, and live pulsing availability badge.
- **About.jsx:** Background overview (UNINOVE & computer science studies).
- **Experience.jsx:** Professional history detailing financial and administrative background.
- **Skills.jsx:** Interactive grid showcasing core technical competencies with hover states.
- **Projects.jsx:** Featured projects showcase featuring interactive spotlight glass-cards.
- **ScrollToTop.jsx:** Interactive scroll state helper button for smooth navigation.
- **Footer.jsx:** Copyright and location details.
